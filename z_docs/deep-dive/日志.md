## 二、Speech 口型演进（`main.ts`）

| 版本 | 方案 | 问题 |
|------|------|------|
| v1 | 持续张嘴 | 打哈欠 |
| v2 | `setTimeout` 链交替开/关 | 只有 2 态，机械 |
| v3 | 5 音素 + 标点停顿 180-380ms | 长文本偏差 ~3s |
| **v4** | 取消标点特殊处理，`totalMs / 字符数` 精确平分 | ✅ |

**v4 核心逻辑**：
```ts
const interval = Math.round(durationMs / chars.length);  // 80-250ms
// setTimeout 链，每周期 ±40ms 抖动 + 幅度 ±15% 随机选音素
```

验证：14 字→3839ms/14 cycles（100%），105 字→20447ms/103 cycles（98%）。

## 三、TTS 语音合成（`core/tts_engine.py` 新建）

**架构**：`synthesize_async()` → 后台线程合成 MP3 → `queue.Queue` → 主线程 `QTimer`(200ms) 轮询 → 播放 + 启口型。

| API | 说明 |
|-----|------|
| `synthesize_async(text, voice)` | 后台合成，入队 `(path, duration)` |
| `get_ready()` → `(path, sec) | None` | 非阻塞轮询 |
| `play_file(path)` | 主线程播放 |

语音：`xiaoxiao`(女)/`yunxi`(男)/`xiaoyi`(温柔)/`yunjian`(沉稳)。MP3 按 `hash(text)` 缓存。

**调用链**（`main_window.py`）：
```python
synthesize_async(reply, "xiaoxiao")
# QTimer 每 200ms 轮询 → play_file + startSpeechLipSync(text, exactMs)
```
